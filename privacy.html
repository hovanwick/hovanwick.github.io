Privacy Policy

Last updated: October 2026

FlowKit is a personal, self-hosted tool used only by its owner to upload videos to the owner's own YouTube channel.

Data accessed

With the owner's consent, FlowKit uses the YouTube Data API to upload videos, set their thumbnails, and read the channel name. It requests the scopes youtube.upload and youtube.readonly.

Storage and sharing

OAuth tokens are stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

FlowKit's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API use is subject to the YouTube Terms of Service and the Google Privacy Policy.
